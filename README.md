# VSM 產線分析工具

這是一個純前端網頁工具。使用者可輸入月需求、工作天、班別、工時及各站製程資料，即時計算 Takt、瓶頸月產能、負荷率、現況與目標 WIP、VA／NVA 與 Lead Time。

## 使用方式

- 網站入口：`dist/index.html`
- 可新增或刪除站別，最多 20 站；畫面會顯示目前站數並在達到上限時停用新增按鈕。
- `C/O Changeover Time` 代表換線／切換時間，單位為分鐘；匯入時仍相容舊欄位名稱 `OCTc`。
- 可下載 `VSM站別匯入範本.xlsx`，填寫後由「匯入 Excel」整批帶入站別資料並重新計算；範本已嵌入下載按鈕，不受部署平台的二進位檔案傳輸方式影響。
- 匯入會驗證必要欄位、數字範圍、重複站別與 20 站上限，套用前會要求確認。
- 「匯出 Excel」會下載包含生產摘要、站別資料與價值流時間軸的 `.xlsx` 檔。
- 「匯出 PDF」會建立 A4 橫向專用報表，第一頁整合即時結果與現況 VSM；每頁最多 4 個完整站別，超過時自動分頁，製程框、WIP 與時間軸不會被頁尾切割。
- 所有計算都在瀏覽器內完成，不會把輸入資料送到外部資料庫。
- Excel 引擎已隨網站放在 `dist/vendor`，不依賴外部 CDN；第三方授權文件一併保留於該資料夾。
- 重新整理頁面會恢復範例資料。

## 雲端部署

將 `dist` 資料夾設定為靜態網站的發布目錄即可。
